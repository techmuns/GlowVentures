# Security identifiers — what each API needs, and what this book has

Generated by `npm run build-symbols` — **do not edit by hand**.

Every live endpoint is keyed on the **NSE trading symbol**. None takes an ISIN
or a name, so a security reaches the APIs if and only if a symbol resolved:

| Endpoint | Sends | Needs |
| --- | --- | --- |
| `/api/quotes` | `ticker_symbol`, `country` | NSE symbol |
| `/api/prices` | `symbol` (+ `.NS` suffix) | NSE symbol |
| `/api/insider` | `ticker`, `country` | NSE symbol |
| `/api/announcements` | `symbol` | NSE symbol |
| `/api/news` | holding name + symbol | NSE symbol |
| `/api/research` — street estimates, concalls, filings | `ticker` | NSE symbol |
| `/api/research` — `/financials` | `<SYMBOL>.NS` | NSE symbol |
| `/api/ratios` | `tickers` | NSE symbol |

**176 reachable · 88 not reachable · 8 not securities at all**
(cash and receivables) — 176 + 88 + 8 = 272, every distinct
security the archive carries.
