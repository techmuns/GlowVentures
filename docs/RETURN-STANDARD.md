# Return calculation — the one standard (for sign-off)

*Prepared for Yamini, 15 November 2026. Task #411: "come to a common standard for return
calculation" used on every surface. This note states the standard the dashboard already applies
everywhere; once you sign off, it is the agreed reference.*

## 1. One record per question

Every surface that shows a return for the same holding and the same window — the Portfolio Monitor,
the Returns tab, Morning CIO, the return cards — reads **the same selected source record**. No surface
uses a second set of inputs for the same question. When a newer, complete statement arrives it becomes
the selected record for every surface at once.

## 2. What a return counts

A return counts **everything the money earned**:

> unrealised gain + realised gain + income (dividends / distributions, gross of TDS, whether paid out
> or reinvested) ÷ capital deployed (cost of what is still held + cost of the units already sold)

It is never "unrealised ÷ cost" alone, and a figure's worked arithmetic (behind its info button)
carries every one of those terms.

## 3. Which measure, and when — one measure per question, named on its face

| Measure | Used for | Not used for |
| --- | --- | --- |
| **HPR** (holding-period return) | the cumulative % since the first value on record | — |
| **CAGR** | **one** purchase held **a year or more** | staggered money (use XIRR) |
| **XIRR** (money-weighted) | dated external flows + the terminal value on its valuation date | — |
| **Modified Dietz / TWR** | a period return with dated flows inside it | — |

**Under one year:** the absolute return is shown, named as such — never annualised (only debt may be
annualised under a year).

## 4. Benchmarks compare like with like

A money-weighted return is compared only with a money-weighted benchmark (PME): the same index bought
on the **same dated money, over the same window**. A price index is labelled as carrying no dividends
where the holding's own return does.

## 5. Coverage and honesty

- A return is shown **only where the selected record supports it**; otherwise a dash with the reason
  on its face (e.g. "opening value and dated cash flows are missing"). A shown return and a "no dated
  capital" remark never appear together.
- The **latest verified record** is always used. A newer source that is incomplete does not overwrite
  a good earlier one; its date and gap are named.
- **No figure is ever fabricated.** A cost is never used as an opening value; a live quote never dates
  one. Where the data isn't there, the figure is a dash, not a zero or an estimate.
- Exited holdings and closed mandates stay in since-inception gain and capital deployed (no
  survivorship).

## 6. Indian tax basis (where the dashboard shows realised/tax figures)

Short-term = held not more than 12 months (listed equity / equity funds), 24 for unlisted; long-term
starts the anniversary + 1 day; the financial year is 1 Apr – 31 Mar, dated in IST; the ₹1.25 L
s.112A exemption is per person per year; a short-term loss sets off a long-term gain within the year,
a long-term loss a long-term gain only.
