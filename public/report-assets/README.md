Report artwork and fonts
========================

Noto Sans Regular and Bold are from the notofonts/noto-fonts project:
https://github.com/notofonts/noto-fonts/tree/main/hinted/ttf/NotoSans
Their SIL Open Font License is included in OFL.txt. Embedded fonts preserve
searchable rupee symbols and legible text in downloaded PDFs.

yacht-cover.jpg was generated with the built-in ImageGen tool for this report,
using the user's yacht-cover screenshot as a visual reference, then encoded
as JPEG. The screenshot and reference PDF are not shipped with the application.

Generation prompt:
"Match the supplied first reference image's yacht photograph: a single white
luxury motor yacht viewed perfectly from overhead, vertically oriented with bow
toward top, stationary in deep dark teal clear ocean, small tender below.
Portrait composition 1024x1536, boat in lower-middle, large calm dark ocean
negative space above for a logo. Premium understated aerial photography,
subtle rippling water, natural daylight. Only create the photograph. No text,
no logos, no borders, no report layout, no UI."

The PDF draws the existing Glow Ventures G wordmark as vectors and credits
Munshot AI. Its interior palette and landscape layout follow the supplied
report reference; all figures come from the selected Morning CIO snapshot.
